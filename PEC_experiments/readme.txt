# PEC Calibration Code — Supplementary Materials (Appendix A)

## Description
This repository contains the Python implementation of the conceptual
nutrient–phytoplankton (NP) model developed for the Paranaguá Estuarine
Complex (PEC), together with the computational experiments used to
benchmark and validate the parameter-calibration workflow.

The codebase reproduces the numerical experiments presented in
Chapters 1,2, and 5, and Appendix A of the associated PhD thesis, 
including twin experiments, one-parameter and two-parameter calibration
scenarios, and structured reporting.

## Relation to the Thesis
Yamashita, L. B. (2026). *A Data-Constrained Framework for Marine
Biogeochemistry Modeling with Applications to the Paranaguá Estuarine
Complex*. PhD Thesis, Universidade Federal do Paraná.

Relevant sections:
- Chapter 1, Section 1.4 — Developing a model in practice
- Chapter 2, Section 2.2 — Model development
- Chapter 5, Section 5.1 — Benchmarking and validating the approach
- Chapter 5, Section 5.2 — Fitting the model to observations
- Chapter 5, Section 5.3 — Estimating the nitrate input from rivers, 
                           rain, and human activities
- Appendix A — Implementation and Computational Experiments


Repository Contents
-------------------
## Core Module
-------------------
- 'PEC_aux_functions.py'
  Centralized implementation of:
    * Data loading and preprocessing
    * Construction of cyclic environmental forcings
    * Two-box NP model ODE system
    * Numerical integration with robustness safeguards
    * Observation generation (real and artificial)
    * Heuristic-search utilities
    * DFO-LS-compatible model interfaces
    * Automated PDF report generation

This module is shared by all experiment executables.

-------------------
## Executables
-------------------
- 'PEC_model_Chapter_1.py'
  Chapter 1 — Short-time NP biochemical experiment

  Implements a minimal, self-contained Nutrient–Phytoplankton (NP)
  model used for conceptual illustration and short-time simulations.

  Workflow:
    1. Explicit definition of a single-box NP ODE system
    2. Short-time numerical integration (order of days)
    3. Synthetic parameter and initial-condition setup
    4. Structured JSONL output
    5. Automatic 1-page PDF report generation (N and P dynamics)


- 'PEC_model_Chapter_2.py'
  Chapter 2 — Biogeochemical modeling experiments for the 
              Paranaguá Estuarine Complex

  Performs biogeochemical simulations under realistic environmental
  forcings, including sensitivity to anthropogenic nutrient inputs.

  Workflow:
    1. Long-term model spin-up under natural environmental conditions
    2. One-year simulation with extraction of the final annual cycle
    3. Fitting and comparison with observational data
    4. Simulation with increased riverine nitrate supply
    5. Structured JSONL output
    6. Automatic 2-page PDF report generation (one page per experiment)

- 'PEC_experiments_5_1.py'
  Section 5.1 — Benchmarking and validating the parameter calibration approach

  Performs a two-parameter calibration experiment (Vmax, lambda)
  using artificial observations generated by the model itself.

  Workflow:
    1. Artificial-observation generation
    2. Two-dimensional grid-based heuristic search
    3. DFO-LS optimization
    4. JSON output and automatic PDF report generation

- 'PEC_experiment_5_2.py'
  Section 5.2 — Fitting the model to "real" observations

  Performs a one-parameter calibration experiment using observational
  nitrate and chlorophyll data.

  Workflow:
    1. Observation generation from weighted field data
    2. One-dimensional heuristic search over lambda
    3. DFO-LS optimization
    4. JSON output and automatic PDF report generation

- 'PEC_experiment_5_3.py'
  Section 5.3 — Estimating the nitrate input from rivers, rain, and human activities

  Performs a one-parameter calibration experiment targeting the
  riverine nitrate contribution factor.

  Workflow:
    1. Observation generation from weighted field data
    2. One-dimensional heuristic search over w
    3. DFO-LS optimization
    4. JSON output and automatic PDF report generation

## Data
-------------------
- 'dataset.jsonl': Environmental and tracer datasets.
  JSON Lines file containing environmental forcing data, biological
  observations, and species composition used by the model.


## Execution Modes for Chapter 5 experiments
--------------------------------------------
All executables related to Chapter 5 support two modes:

- Light mode
  Activated via:
      PEC.set_light_mode(True)

  Intended for numerical smoke tests and quick validation of code
  execution. Uses reduced integration horizons and grid sizes.

- Full mode
  Intended to reproduce the experiments reported in the thesis.
  Requires setting:
      PEC.set_light_mode(False)

## Requirements
---------------
- Python 3.9+
- numpy
- scipy
- dfols
- matplotlib (for report generation)


## Reproducibility Notes
------------------------
- The annual cycle is represented as 360 days (12 months × 30 days),
  consistent with the numerical experiments reported in the thesis.
- Results are written as structured JSONL files and summarized
  automatically in two-page A4 PDF reports.
